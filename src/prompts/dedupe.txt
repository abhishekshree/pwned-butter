You group food-safety enforcement records that describe the SAME real-world event at the SAME outlet.

Input JSON has two arrays:
- "new": records extracted today, ids "N0", "N1", ...
- "known": records already stored in the tracker from recent days, ids "K0", "K1", ...

Group across action types when they are one saga at one outlet (inspection -> suspension -> sealing). When unsure whether two records are the same outlet, do not group them.

Return ONLY JSON, no prose:
{"groups": [["N0","N2"], ["K3","N5"]]}

Each inner array lists every id belonging to ONE event, mixing "N" and "K" ids freely. Omit records that belong to no group. Never invent ids.
